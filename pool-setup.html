각 Worker 채팅은 실제 목표를 시작하기 전에 GitHub 읽기 preflight를 수행합니다. 승인 카드가 나타나면 그 채팅에서 모든 작업 허용 / Always allow 같은 지속 허용 옵션을 직접 선택하세요. Rerun은 승인 버튼을 자동으로 누르지 않습니다.

GitHub 읽기가 실제로 성공하고 해당 채팅이 worker-ready JSON을 생성한 경우에만 Worker가 READY가 됩니다. 모든 Worker가 READY가 된 뒤 1번 Worker가 자동으로 목표를 시작합니다.
