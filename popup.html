Start/Stop은 현재 ChatGPT 탭의 GitHub watcher만 켜고 끕니다. GitHub의 `continue / complete / needs_user / blocked` 상태와는 독립적입니다. watcher가 켜져 있으면 terminal 상태에서도 설정된 주기로 계속 확인하고, GitHub가 다시 `continue`가 되면 자동 재개합니다.

현재 채팅을 Rerun에 연결

새 탭은 저장소 좌표를 상속하지 않고 Unconnected로 시작합니다. 연결 프롬프트는 Side Panel 값을 추측에 사용하지 않고, 이 채팅이 GitHub 앱으로 실제 사용한 repository와 branch를 확인합니다. 아직 실제 GitHub 프로젝트를 사용하지 않았다면 아무 파일도 쓰지 않고 `UNCONNECTED`라고 알려줍니다.

대상이 하나로 확인되면 Rerun 5문서를 생성/보완한 뒤 채팅에 repository, branch, control path, run/status/task, 프로젝트 목표를 연결 결과로 명확히 알려줍니다.

처음에는 Owner / Repository / Branch가 비어 있는 것이 정상입니다. `Rerun 연결 프롬프트`가 채팅에 출력한 CONNECTED 결과를 확인한 뒤 그 좌표를 입력하고 Save한 다음 Start해서 watcher를 켭니다. 같은 GitHub control stream은 동시에 한 탭만 감시할 수 있습니다. 표준 control이 없는 저장소에서 좌표를 직접 입력하고 Start한 경우의 자동 bootstrap은 fallback으로 유지됩니다.
