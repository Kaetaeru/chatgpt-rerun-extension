새 프로젝트를 Rerun에 연결

이 대화가 이미 작업 중인 GitHub 저장소를 알고 있다면, 먼저 연결 프롬프트를 보내 `.chatgpt-rerun`의 README / PLAN / STATE / STATUS / control 문서를 생성하거나 안전하게 보완합니다. Rerun 실행은 시작하지 않습니다.

권장 흐름은 `Rerun 연결 프롬프트`로 프로젝트 문서를 먼저 준비한 뒤 Owner / Repository / Branch를 확인하고 Start하는 것입니다. 같은 GitHub control stream은 동시에 한 탭만 실행할 수 있습니다. 표준 control이 없는 상태에서 Start한 경우의 안전한 자동 bootstrap은 fallback으로 유지됩니다.
