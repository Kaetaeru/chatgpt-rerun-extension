Start and Stop control only the GitHub watcher attached to this ChatGPT tab. The watcher is independent from GitHub work states such as continue, complete, needs_user, and blocked. Terminal work states pause dispatch but do not turn the watcher off.

Connect this conversation

New ChatGPT tabs start Unconnected. The connection prompt must identify the repository and branch that this conversation actually used through the GitHub app; it must not guess from Side Panel values.

Once the target is unambiguous, the conversation installs or reconciles the durable GitHub protocol and reports the exact repository, branch, control path, run, status, task, and goal.

When enabled, automation pauses while ChatGPT shows a GitHub approval card. The extension never clicks approval controls. After you approve manually and the card disappears, execution can continue automatically.

There is no lifetime send cap. Only repeated sends for the same unchanged control generation are bounded by the per-sequence retry limit.

An authenticated GitHub token enables faster conditional polling. Without a token, the watcher automatically slows down to stay within public API limits.
